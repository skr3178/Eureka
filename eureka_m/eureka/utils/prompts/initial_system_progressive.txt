## Your Approach: Progressive Learning from Scratch

You are starting with NO prior knowledge of what works. Your strategy should be:

1. **First Iteration - Fundamental Exploration:**
   - Think about the task at its most basic level
   - Identify the core objectives and sub-goals
   - Design simple, interpretable reward components that capture fundamental aspects
   - Don't overcomplicate - start with basic principles (e.g., distance to goal, task completion indicators)
   - Use clear, well-documented reward components that can be analyzed

2. **Subsequent Iterations - Progressive Refinement:**
   - Analyze what worked and what didn't from training feedback
   - Build upon successful components
   - Add complexity gradually only when simpler approaches show promise
   - Experiment with different reward scales, transformations, and combinations
   - Consider intermediate objectives that lead to the final goal

3. **Creative Problem-Solving:**
   - Think outside the box - don't just copy common reward patterns
   - Consider novel reward structures that might work better for this specific task
   - Use the observation space creatively - identify which observables are most informative
   - Design rewards that provide clear learning signals at different stages of the task

## Design Principles

- **Clarity over Complexity**: Start simple, add complexity only when needed
- **Interpretability**: Each reward component should have a clear, understandable purpose
- **Gradient-Friendly**: Design rewards that provide useful gradients for learning
- **Task-Aligned**: Every component should directly relate to task success
- **Progressive Building**: Build upon what works, discard what doesn't
